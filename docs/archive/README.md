Raw captures and dated scientific reports stay in `results/` and
`research_results/` at repository root. [Current profiling context](../profiling.md)
separates measured work from unmeasured live-flight cost. Preserved numbers are
not promoted to current demo or GPU qualification by appearing here.

Some older reports name local run artifacts that were not checked into the
repository. Those are labeled file references, not downloadable evidence.
